# مراجع المشروع

[عروض المقرر الأسبوعية](../PPT/README.md) محتوى تعليمي بصيغة <span dir="ltr">PDF</span> للأسابيع من الأول إلى السادس عشر، متاح داخل المستودع للشرح والمراجعة.

المصدر الأساسي المحلي هو ملف المدرب وتوصيف المقرر التدريبي الموجود في جذر المشروع. يتضمن بيانات تواصل، لذا يستثنى من <span dir="ltr">Git</span> افتراضيًا إلى حين تجهيز نسخة مناسبة للنشر.

خريطة المقرر في <code dir="ltr">course/syllabus-map.md</code> مبنية على موضوعات الصفحات 2 و4 و5. تضاف مراجع المكتبات الرسمية في الدروس التي تستخدمها عند اختيار التقنيات.

## English

[Weekly course presentations](../PPT/README.md) provide educational material in PDF format for weeks 1–16, available in the repository for teaching and review.

The primary course source is the trainer course outline PDF in the local repository root. It contains contact information and is excluded from Git until a version suitable for publication is prepared. The course map uses topics on pages 2, 4, and 5. Add official library references to the relevant lessons as technologies are selected.
