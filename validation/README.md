# تسجيل نتائج التجارب

سجل اختبارًا مستقلًا لكل تمرين وجهاز ونظام. نجاح التجربة على <span dir="ltr">Windows</span> أو لوحة واحدة لا يثبت دعم اللوحتين.

1. أكمل بيانات القطع والإعدادات الفعلية.
2. نفذ التمرين من نسخة جديدة من المستودع.
3. سجل الأمر والنتائج المتوقعة والفعلية والتاريخ والإصدارات والمشكلات.
4. انسخ [قالب النتيجة](run-record.example.json) إلى سجل باسم التمرين والجهاز والتاريخ دون بيانات خاصة.
5. حدّث [مصفوفة التوافق](compatibility.md) واربطها بالسجل.

لا توجد نتائج فعلية على <span dir="ltr">Raspberry Pi</span> حتى الآن. ملفات الأمثلة ليست سجلات نجاح.

</div>

<div dir="ltr" lang="en">

## English

Record a separate run per lab, board, and OS. Windows or single board success does not prove dual board support. Complete hardware and settings, follow the lab from a fresh checkout, record commands and expected and actual results with date and versions, copy the JSON template to a named record without private data, and update the linked matrix. No Pi hardware run exists yet. Example files are not successful test results.
