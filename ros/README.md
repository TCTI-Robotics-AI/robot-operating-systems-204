# تجارب ROS

مكان حزم Catkin وملفات launch عند تنفيذ دروس ROS. لا توجد حزم قابلة للبناء هنا حاليًا.

تبدأ المرحلة بعقدة تستقبل أمر اللمبة وتعيد نتيجة، ثم تربط بالصوت وبموصل الجهاز. تحدد أسماء الرسائل والمواضيع والخدمات في توثيق التجربة قبل إضافة الحزم.

## English

This directory is reserved for Catkin packages and launch files. No buildable ROS package exists yet. The first planned node will accept a lamp request and return its result, followed by speech and device adapter integration. Document message, topic, and service names before implementing the packages.
