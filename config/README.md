# إعدادات البيئات

تضاف هنا إعدادات تجريبية عامة بعد تحديد نظام Pi 5 ومكتبات الأجهزة. توثق إعدادات Pi 4 وPi 5 بشكل مستقل عند اختلافها.

أرقام GPIO والأجهزة الصوتية لم تعتمد بعد. تحفظ مفاتيح الخدمات محليًا خارج Git، وتضاف أسماء المتغيرات المطلوبة فقط في أمثلة الإعداد.

## English

Public configuration examples will be added after confirming the Pi 5 OS and device libraries. Document Pi 4 and Pi 5 settings separately where they differ. GPIO pins and audio devices have not been selected. Keep service secrets local and outside Git; examples should list required variable names only.
