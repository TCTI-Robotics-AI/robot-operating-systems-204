# أنظمة تشغيل الروبوتات

**رمز المقرر: 204 روبوت** · Robot Operating Systems · [English](README.en.md)

مستودع المقرر التعليمي، يجمع تمارين Linux وROS والمحاكاة والصوت والمحادثة والتحكم بالأنظمة المدمجة. لكل تمرين شرح ومتطلبات وإعدادات ونتائج تحقق مستقلة بالعربية والإنجليزية. التحكم المنزلي بالصوت وWhatsApp تطبيقات ضمن المقرر وتوسعاته.

## البداية

1. راجع [خريطة المقرر](docs/course-map.md) و[فهرس التمارين](labs/README.md).
2. حدد جهازك من [دليل البيئات](environments/README.md).
3. راجع [قائمة القطع والتوصيل](hardware/README.md).
4. نفذ التمرين وسجل النتيجة حسب [دليل التحقق](validation/README.md).

المتوفر الآن هو [التحكم النصي بلمبة افتراضية](labs/07-gpio-control/01-text-lamp/README.md). بقية مجلدات التمارين تحدد النطاق المطلوب، وليست تطبيقات مكتملة.

## الأجهزة والتوافق

Pi 4 وPi 5 جهازان مستهدفان للمدرب والمتدربين. تختلف خطوات النظام والصوت وGPIO عند الحاجة، بينما يبقى الهدف التعليمي واحدًا.

| الجهاز | مسار النظام | اختبارات المشروع |
| --- | --- | --- |
| Raspberry Pi 4 | Ubuntu 20.04 بنظام 64 بت لمواءمة المنهج | لم يختبر على الجهاز |
| Raspberry Pi 5 | Ubuntu 24.04 بنظام 64 بت كمسار مقترح مدعوم للجهاز | لم يختبر على الجهاز |

Ubuntu 20.04 ليس مسار تثبيت مباشر مدعومًا على Pi 5. توفر نظام مدعوم للجهاز لا يثبت توافق ROS أو المايك أو GPIO؛ توثق النتائج لكل تمرين على حدة. [التفاصيل والمصادر](docs/environments.md).

## تجربة أولى دون أجهزة

من جذر المستودع على Linux، باستخدام Python 3.8 أو أحدث:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m arabic_home --command "شغل اللمبة"
python -m arabic_home --command "طفي اللمبة"
```

يعرض المثال حالة لمبة افتراضية دون استخدام الصوت أو GPIO أو ROS. كل تشغيل مستقل ولا يحفظ الحالة.
