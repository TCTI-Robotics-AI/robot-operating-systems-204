# مشروع تعليم ROS والتحكم المنزلي بالصوت العربي

العربية | [English](README.en.md)

مشروع تعليمي لمقرر أنظمة تشغيل الروبوتات 204 روبوت. يربط أساسيات ROS والمحاكاة والمحادثة والتحكم بالأنظمة المدمجة، ويبدأ بتطبيق تشغيل لمبة وإطفائها بأوامر عربية.

## الحالة الحالية

بنية أولية مع تجربة نصية للمبة افتراضية. استقبال الصوت وROS والتحكم الفعلي والتكاملات الخارجية مراحل لاحقة، وليست وظائف جاهزة حاليًا.

## بيئات العمل

| المسار | الجهاز | النظام | حالة التحقق |
| --- | --- | --- | --- |
| المتدرب | Raspberry Pi 4 | Ubuntu 20.04 بنظام 64 بت | بيئة مستهدفة تحتاج اختبارًا على الجهاز |
| التطوير | Raspberry Pi 5 | نظام مدعوم يحدد بعد فحص الجهاز | بيئة مستهدفة تحتاج اختبارًا على الجهاز |

توافق المشروع مع الجهازين هدف نتحقق منه عمليًا لكل مرحلة. Ubuntu 20.04 ليس نظام تثبيت مباشر مدعومًا رسميًا على Pi 5. تفاصيل القرارات في [دليل البيئات](docs/environments.md).

## تشغيل التجربة الأولى

على Linux من داخل مجلد المشروع، باستخدام Python 3.8 أو أحدث:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m arabic_home --command "شغل اللمبة"
python -m arabic_home --command "طفي اللمبة"
```

تظهر حالة اللمبة الافتراضية. كل تشغيل تجربة مستقلة؛ لا يحفظ حالة ولا يشغّل أطراف الجهاز. للتفاصيل راجع [التجربة الأولى](lessons/01-text-lamp/README.md).

## تنظيم المشروع

```text
docs/                 الشرح وقرارات التصميم وخطة المقرر
lessons/              التجارب التعليمية وأهدافها وتمارينها
src/arabic_home/      منطق الأوامر وتجربة التشغيل
ros/                  حزم ودروس ROS عند تنفيذها
simulation/           نماذج الروبوت والمحاكاة عند تنفيذها
config/               إعدادات البيئات عند اعتمادها
hardware/             القطع والتوصيلات عند تحديدها
integrations/         تكاملات اختيارية مثل WhatsApp
references/           فهرس مصادر المقرر
.github/              قوالب البلاغات والمساهمات
```
