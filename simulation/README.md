# محاكاة الروبوتات

مكان تجارب الروبوت بعجلتين والذراع، وملفات URDF وXacro وعوالم Gazebo وإعداد RViz عند تنفيذها. تخدم الأسابيع 6 إلى 10 من المقرر. لا توجد نماذج محاكاة جاهزة حاليًا.

## English

This directory is reserved for mobile robot and arm experiments, URDF and Xacro descriptions, Gazebo worlds, and RViz configurations. These lessons cover weeks 6 to 10. No runnable simulation model is available yet.
