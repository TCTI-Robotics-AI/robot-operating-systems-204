## English

Each directory is an independent course lab. Numeric IDs organize topics and are not course week numbers. Only the GPIO text demo is implemented. Other lab guides define scope and prerequisites. Every lab targets Pi 4 and Pi 5, with actual hardware validation tracked separately. Speech, AI models, and WhatsApp have independent labs; voice home automation integrates completed components.
