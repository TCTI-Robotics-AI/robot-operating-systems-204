# قالب تمرين المقرر

يكتب بنفس المحتوى بالعربية والإنجليزية. القيم غير المعروفة تسجل بأنها غير محددة، ولا تنشر كإعداد جاهز.

## تعريف التمرين

الرقم والعنوان والهدف وأسبوع المقرر والمتطلبات السابقة والحالة ومجلد الكود. هل <span dir="ltr">ROS</span> مطلوب أو اختياري أو غير مستخدم؟ ما إصداره وطريقة بنائه؟

## القطع والبرامج

الكميات والموديلات والقيم ومواصفات الطاقة وإصدارات النظام و<span dir="ltr">Python</span> و<span dir="ltr">ROS</span> والمكتبات وأدوات البناء ومزود الخدمة عند الحاجة.

## إعداد <span dir="ltr">Pi 4</span>

النظام والمعمارية والتثبيت وتفعيل الأجهزة والصوت ومكتبة <span dir="ltr">GPIO</span> ونوع ترقيم الأطراف والتوصيل والتشغيل.

## إعداد <span dir="ltr">Pi 5</span>

المعلومات نفسها، مع كل فرق عن <span dir="ltr">Pi 4</span>. لا يعلن توافق إعداد غير مختبر.

## التوصيل والإعدادات

مخطط بالإشارات وأرقام <span dir="ltr">BCM</span> والأطراف الفيزيائية والأرضي والجهود وقيم المكونات، وعينة إعدادات دون أسرار. للتجربة البرمجية فقط يوضح أن التوصيل غير منطبق.

## التنفيذ والنتائج

أوامر مرتبة ومشروحة، إدخال وإخراج ومعيار نجاح، أخطاء شائعة وحلولها، وتمرين إضافي.

## سجل التحقق

رابط لسجل كل جهاز يشمل التاريخ والقطع والإصدارات والنتيجة والفروق والمشكلات. حدث المصفوفة؛ هدف الدعم ليس نتيجة اختبار.
