# التكاملات الاختيارية

مكان توسعات النموذج اللغوي وWhatsApp عند تنفيذها. ليست مطلوبة للتجربة النصية، ولم تعتمد خدمة أو حساب أو مكتبة حاليًا.

لكل تكامل دليل إعداد وتكلفة ومتطلبات اتصال ومثال مستقل. لا تحفظ مفاتيح الخدمات أو المحادثات أو أرقام المتدربين داخل المستودع.

## English

This directory is reserved for optional language model and WhatsApp integrations. Neither is required for the text demo, and no provider, account, or library has been selected. Each integration needs its own setup guide, cost and connectivity requirements, and standalone example. Keep service keys, conversations, and learner phone numbers outside the repository.
