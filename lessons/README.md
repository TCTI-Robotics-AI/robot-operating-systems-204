## English

The available lesson is [text control of a simulated lamp](01-text-lamp/README.md). Use the [lesson template](../docs/lesson-template.md) for new experiments and map each one to the course. Audio, hardware, ROS, and simulation lessons will be added in stages. Every lesson should include Arabic and English explanations.
