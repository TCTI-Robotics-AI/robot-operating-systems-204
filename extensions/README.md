# Course extensions and applications

Extensions build on course labs and do not change syllabus numbering or count as original syllabus items. The [voice assistant](voice-home-automation/completion.md) is complete for its agreed Pi 5 scope: wake, physical LED control, date, Jeddah temperature and Arabic spoken replies. Language-model and WhatsApp extensions remain planned. Specify ROS use per variant; modern language models do not replace the course AIML lesson. Record both board paths, parts, software versions and actual results before claiming compatibility.
