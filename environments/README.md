# دليل اختيار بيئة التشغيل

اختر المسار حسب الجهاز والنظام ثم متطلبات التمرين. لا تفترض أن جميع التمارين تستخدم نفس مكتبات الصوت أو <span dir="ltr">GPIO</span> أو <span dir="ltr">ROS</span>.

| الجهاز | ملف الإعداد |
| --- | --- |
| <span dir="ltr">Pi 4</span> مع <span dir="ltr">Ubuntu 20.04</span> | [دليل <span dir="ltr">Pi 4</span>](pi4-ubuntu2004/README.md) |
| <span dir="ltr">Pi 5</span> مع <span dir="ltr">Ubuntu 24.04</span> المقترح | [دليل <span dir="ltr">Pi 5</span>](pi5-ubuntu2404/README.md) |

سجل النظام الفعلي و<span dir="ltr">Python</span> والمايك ومخرج الصوت ومكتبة <span dir="ltr">GPIO</span> و<span dir="ltr">ROS</span> في سجل التحقق. ملفات <span dir="ltr">JSON</span> أمثلة بيانات فقط؛ لا يقرأها البرنامج الحالي ولا تثبت حزمًا.

## English

Choose a profile by board and OS, then follow lab requirements. Audio, GPIO, and ROS dependencies are selected per lab. The guides describe the Pi 4 course track and proposed Pi 5 track. Record actual OS, Python, audio devices, GPIO library, and ROS versions. JSON examples document data; the current demo does not load them or install packages.
