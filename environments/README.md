# دليل اختيار بيئة التشغيل

اختر المسار حسب الجهاز والنظام ثم متطلبات التمرين. لا تفترض أن جميع التمارين تستخدم نفس مكتبات الصوت أو GPIO أو ROS.

| الجهاز | ملف الإعداد |
| --- | --- |
| Pi 4 مع Ubuntu 20.04 | [دليل Pi 4](pi4-ubuntu2004/README.md) |
| Pi 5 مع Ubuntu 24.04 المقترح | [دليل Pi 5](pi5-ubuntu2404/README.md) |

سجل النظام الفعلي وPython والمايك ومخرج الصوت ومكتبة GPIO وROS في سجل التحقق. ملفات JSON أمثلة بيانات فقط؛ لا يقرأها البرنامج الحالي ولا تثبت حزمًا.

## English

Choose a profile by board and OS, then follow lab requirements. Audio, GPIO, and ROS dependencies are selected per lab. The guides describe the Pi 4 course track and proposed Pi 5 track. Record actual OS, Python, audio devices, GPIO library, and ROS versions. JSON examples document data; the current demo does not load them or install packages.
